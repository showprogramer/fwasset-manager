## 目标

按已确认原型重排程序资产工作台：操作按作用范围归位，不改任何服务与写入语义。

## 规则

- 左栏：顶部「当前型号」可搜索下拉 + `⋯` 菜单（新增 / 重命名 / 删除型号）；下方分类列表「全部程序 / 通用模块 / 定制方案」，条目右侧显示数量；定制方案节标题带 `+`（新建方案），方案行右键重命名 / 删除。型号 chips 与「型号管理」「方案管理」按钮移除。
- 主区：面包屑标题（型号 › 分类）+ 搜索；命令行只有主按钮「新建程序」和依赖选中项的「更新」「备用版本」。针对单个程序的关联 / 目录 / 删除只在详情底部和表格右键，不在命令栏重复。
- 提示：撤销、恢复、未配置提示改为表格上方的内联提示条；撤销与继续恢复以链接形式出现。
- 表格：列为 类型 / 程序名称 / 版本 / 归属；归属用标签绘制，关联行显示警示色「来自 源型号」（界面称「关联」，代码仍为 `shared_*` / `borrow_*`，见 architecture.md）。程序文件移入详情。
- 右侧详情：选中程序的名称、类型与归属标签、版本、厂商（铅笔 = 改厂商）、文件、方式；按 flash_mode 挂载操作面板；U 盘选择器只在 auto_usb 时出现在主按钮上方；底部为目录 / 复制路径 / 关联 / 删除。长名称与文件名在 `_ - .` 处换行，悬停看全名。tool_launch 只在找到工具时显示「打开烧录工具」，不展示路径与配置提示（是否保留该功能待定）。
- 底部状态栏：程序数与索引时间；右侧「活动」显示新错误数，点击弹出运行日志。
- 「重新读取程序文件夹」迁到「软件修复」页；软件修复与设置沉到导航底部。
