# TASK-20260916-quarantine-records-undo：隔离区两类记录与撤销

状态：已完成

## 目标与规则

本任务是 [CRUD 写语义](TASK-20260903-crud-write-semantics.md) 子任务 1 的收尾切片，交付 D2.5 的**隔离记录与撤销层**。隔离根本身（`managed_paths.quarantine`、同卷兄弟目录 `.fwasset-quarantine`、所有权标记与路径守卫）已由 TASK-20260905 / TASK-20260915 交付，本任务**不重做根基础设施**。

D4.3（`managed_path_reason` / `should_exclude_managed_path`）与 D4.5（USB `ignore`）经核对已在 `core/managed_paths.py` 与 `core/usb_ops.py` 落地，不属本任务范围；父规格第 1 项对这两项的归属记录需相应收口。

### 范围

- `core/quarantine.py`（新模块）：隔离记录的登记、查询、撤销、到期清理与启动恢复。
- `core/types.py`：`QuarantineKind`、`QuarantineRecord` 等公共类型真源。
- 不接 UI，不接 service 层错误码映射，不实现具体删除业务入口（归子任务 4/5）。

### 规则（父规格 D2.5，逐条不得放宽）

- **两类记录**：
  - `undoable_delete`——D10.1 各删除操作，保留 5 秒撤销窗口；
  - `transactional_retire`——update / 改类型的旧程序退位，**仅供失败补偿**；提交成功后立即异步送系统回收站，**不展示撤销**。送出失败保留清单供启动恢复，但**不得**因此重新承诺 update 可撤销。
- **隔离根位于工作区同卷的受控兄弟目录**，路径由应用生成、不接受用户输入、扫描排除。无法建立同卷隔离根 → `trash_unavailable`；**首批不做跨卷分支**（不实现跨卷复制、逐项校验与退位）。
- **持久化操作清单**：原路径、内容 hash（复用 `core/manifest.py` 的 `directory_manifest_hash`，不含 mtime）、状态、时间。清单读写沿用 `workspace_transaction` 的原子替换与有界重试模式，不新造一套。
- **撤销窗口届满后异步送系统回收站**，不等应用退出。崩溃后下次启动按持久化清单恢复处理。

  **调用链归属（2026-09-16 统筹裁决）**：本片只交付异步清理入口与启动恢复函数，并声明调用契约；实际触发点不在本片——删除入口（D2.4 / D2.4a）归子任务 4/5，应用启动时的恢复调用归子任务 8 UI 编排。本片不提前拉入尚未实现的删除入口。
- **锁归属（2026-09-16 统筹裁决）**：父规格 D2.4 失败补偿「全程持写锁」且 D8.3 要求删除接入同一事务协调器，故隔离登记/撤销/清理发生在**调用方已持有的写锁内**。`core/quarantine.py` 的公共函数一律**接收外部锁/事务，不自行获取** `WorkspaceLock`；同进程重入 fail-fast 是既有事务基础的正确行为，不得为迁就本模块放宽。
- **撤销目标被占用 → `undo_conflict`，隔离内容不得删除。**
- 与 D4 `旧版本/` 是两套机制，保留根、元数据、生命周期均不同，不得合并实现。
- 撤销还原路径须过 `assert_within_workspace` 与 D3 的存在性判定（含大小写、junction 等价身份）；命中已存在目标即 `undo_conflict`，不覆盖。

### 人工验证步骤（最短路径）

本片无 UI 入口，按流程用独立临时目录的一次性场景脚本验证，不触碰真实工作区：

1. 建临时工作区目录，取工作区写锁后调用 `register_delete` 删一个测试资产目录 → 确认内容移入同卷 `.fwasset-quarantine` 下的记录目录，原路径消失，清单有记录。
2. 5 秒内调用 `undo_delete` → 确认内容原样移回原路径，内容哈希与登记时一致。
3. 重复步骤 1 后，在原路径手工放一个同名目录再 `undo_delete` → 确认返回 `undo_conflict`，隔离内容仍在、未被删除。
4. 重复步骤 1 后等待超过 5 秒调用 `sweep_expired` → 确认内容送入系统回收站、清单条目清除。
5. 把工作区放在卷根（如 `X:\`）调用 `register_delete` → 确认返回 `trash_unavailable`，不回退跨卷复制。
