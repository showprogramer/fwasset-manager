# REVIEW-20260927-retired-version-ui：备用版本列表与恢复入口

任务：[更新程序对话框与范围下拉](../../../specs/archive/TASK-20260924-update-program-dialog.md)。UI 入口及引用计划公共 API 变化触发独立审查。

## 范围

- `layout_update_service.list_retired_versions` 和 `restore_retired_version` 的恢复边界
- `reference_service.build_rewrite_plan` 的未识别程序 opt-in
- 备用版本对话框、工作台按钮及相关测试

## 发现与处理

| ID | 严重度 | 触发条件与影响 | 处理 |
| --- | --- | --- | --- |
| ISS-20260927-RV1 | 高 | 更新为扫描器暂不识别的文件后，备用副本存在，但恢复服务拒绝当前程序；网格也可能不显示该程序。 | 恢复服务显式校验活动文件与程序路径后允许此类当前程序；引用计划只在恢复入口 opt-in；工具栏支持手选当前程序目录。真实 update→restore 测试通过。 |
| ISS-20260927-RV2 | 中 | 恢复返回哈希变化、路径占用等普通错误时，恢复按钮一直禁用。 | 普通错误重新按选中项启用按钮；恢复态错误关闭对话框。Qt 回归测试通过。 |
| ISS-20260927-RV3 | 低 | 当前程序本体文件被删、仅剩副本时，列表曾显示可恢复，但服务会拒绝。 | 列表复用活动文件检查，显示不可恢复原因；回归测试通过。 |

## 结论

独立审查发现的阻断问题已修复；自动检查结果见任务规格。用户已确认当前工作区整体候选及备用版本的列表、确认与恢复刷新通过。
