# Changelog

本文件按 [Keep a Changelog](https://keepachangelog.com/) 结构维护。
这里只记录用户可感知的功能、重要缺陷修复和必要的兼容性变化；测试命令、任务状态、Review 过程和纯格式化改动记录在对应 Task 或提交中。

## [Unreleased]

### Added

- 仅改厂商、登记/覆盖/解除借用改为受管服务入口：配置根校验、写锁与 generation、CAS 写入；解除借用签发 5 秒内可撤销的恢复令牌。
- 支持改程序类型/范围（清失效的平台默认、旧程序退到隔离区或 `旧版本/`）；工作台可查看备用版本，并将同类型、同方案的副本恢复到原路径，同时把当前程序留作备用。
- 引入「跟随这个程序」借用语义（`follow_asset`）：来源程序重命名、移动和更新后借入方自动同步；旧的「跟随来源默认」登记提供一次性迁移。

### Changed

- 资产索引升级 schema v4：机芯类型与归属厂商纳入搜索缓存；旧版本索引库打开时提示重新扫描生成，固件目录与配置不受影响，仅需一次全量重扫。
- 工作台右键菜单按共享来源和目录操作分组；已登记共享来源时提供更换和取消操作。
- `快捷键`、`快捷按键`、`快捷键-旋钮` 统一使用 catalog 规范键 `快捷键程序`，避免同一模块出现多个默认变体。
- 共享来源登记只展示其它型号的同模块资产，登记对话框同时展示型号、变体和完整路径。
- 型号 id 自动写入接入配置根校验：未配置程序文件夹或型号根越界时不再自动写盘（相关功能只读降级）。

### Fixed

- 修复旧版本索引库升级后按提示重新扫描仍报「版本不兼容」的问题：全量重扫现在会自动重建索引缓存（保留已隐藏项），无需手动删除运行时数据库。
- 复制程序目录到 U 盘时不再带上 `旧版本/` 备用副本和 `程序信息.toml` 内部元数据；程序详情的文件列表也不再显示该元数据文件。
- 统一写入入口的工作区路径守卫，拒绝空根目录、相对路径、词法越界和解析后越界路径。
- 程序文件夹未配置、配置已变更未重新读取、或扫描/烧录任务进行中时，禁止共享登记/取消登记等写入操作，避免写到工作区之外。

### Removed

- 工作台不再提供“设为默认”或默认星标；定制方案只显示本方案程序，不再按旧平台默认配置自动补入通用程序。

## [2026-07]

### Added

- 新增型号持久化 `model_id`、共享引用配置和共享来源解析能力。
- 新增 `follow_default` 共享模式及来源平台选择。
- 新增程序文件夹设置入口和首次配置向导的路径校验。
- 新增工作区扫描、SQLite 资产索引、工具发现和工具使用记录。
- 应用统一使用 PySide6 + QFluentWidgets，移除旧 CTk 界面入口。

### Changed

- 固件资源工作台改为方案和模块卡片为中心的浏览方式，支持搜索、筛选、排序、隐藏和恢复。
- 音乐资源使用目录复制流程；手控/断码屏资源要求配对的 ROM 与 PKG 文件。
- 运行时数据库和日志移至运行时目录，避免污染源码目录。

### Removed

- 移除 Excel 台账、预览缓存 CRUD 和旧蓝牙直连烧录路径；蓝牙固件统一通过外部工具烧录。
- 移除未落地的 `.ref` / `-同X` 自动迁移入口，保留手动共享登记流程。

### Fixed

- 共享来源取消操作按规范模块键删除配置，不删除固件文件；无配置文件时不会凭空写入空文件。
- 修复 catalog 类型优先级、`.mot` 文件识别和多种 ROM 版本格式识别问题。
- 修复共享来源命中后方案回源本地副本、缺失来源错误回退等边界行为。
- 修复配置合并写入丢失未知字段、损坏配置被空配置覆盖和删除共享产生空文件的问题。
- `follow_default` 能兼容 catalog 标签与实际目录名的“程序”后缀差异。

## [2026-05 至 2026-06]

### Added

- 完成固件资产 catalog、通用扫描、服务层和双模式应用基础能力。
- 新增音乐 U 盘流程：格式化、复制目录、完成后安全弹出，并在日志中反馈结果。
- 新增诊断包、后台任务、运行日志和基础 USB 健康检查能力。

### Changed

- 完成源码 `src` 布局、包名统一和可安装启动入口改造。
- 将扫描、刷机、USB 和配置逻辑从 UI 中下沉到 core/service 层。
- 扫描和索引改为 catalog 驱动，SQLite 作为搜索缓存；工作区目录树和 TOML 配置仍是数据源。

### Fixed

- Windows 格式化流程拒绝非 ASCII 盘符，避免无效或危险的 PowerShell 调用。

## [2026-03]

### Added

- 建立固件资产管理应用的 core、UI 和服务分层结构。
- 提供 Windows U 盘扫描、清理、复制、格式化和安全弹出基础能力。
